# WorkBuddy 一键备份

[![下载最新版本](https://img.shields.io/badge/下载-v1.1.0-blue)](https://github.com/mango6i/WorkBuddyBackup/releases/download/v1.1.0/WorkBuddyBackup.exe)

**一句话说明**：把你在 WorkBuddy 里的**所有对话**和**写过的项目代码**打包成一个压缩文件，换电脑或重装系统后，再一键装回去 —— 就像给 WorkBuddy 做一次"整机搬家"。

![主界面](screenshots/01-backup.png?v=3)

---

## 一、我什么时候需要它？

| 场景 | 用它做什么 |
|------|-----------|
| 换新电脑 | 老电脑备份 → 新电脑恢复，对话和代码原样回来 |
| 重装系统 | 重装前备份 → 装完恢复，不用重新聊一遍 |
| 担心数据丢失 | 定期备份一份留档，随时可还原 |
| 想留历史记录 | 把某个项目的完整对话过程保存下来 |

**它备份的是**：对话记录（含全部聊天内容）、自动化任务配置（比如定时签到、领券）、项目源代码，以及空间登记信息。

**它不碰的是**：你的账号密码（不同步任何登录信息）、WorkBuddy 程序本身（需自己在新电脑安装）。

---

## 二、下载与运行

1. 点上面蓝色按钮，或打开：[最新版本下载](https://github.com/mango6i/WorkBuddyBackup/releases/download/v1.1.0/WorkBuddyBackup.exe)
2. 双击 `WorkBuddyBackup.exe` 即可运行 —— **不用安装、不用装 Python**
3. 首次启动会自动找好 WorkBuddy 的数据位置，直接就能用
4. 关闭时点右上角 `×`，可选「退出程序」或「最小化到托盘」

> Windows 若弹出安全提示，选「更多信息 → 仍要运行」。
> 启动时会显示几秒「正在启动」画面，属正常现象。

## 三、备份（3 步搞定）

![备份页](screenshots/01-backup.png?v=3)

**第 1 步**：打开软件，默认就在「备份」页，对话列表会自动列出来（和你 WorkBuddy 左侧边栏一样：任务 / 空间两组）。

**第 2 步**：勾选要备份的对话

| 你想做什么 | 怎么点 |
|------------|--------|
| 勾选 / 取消某条对话 | 点它的复选框，或点对话名 |
| 折叠 / 展开一个空间 | 点空间名（前面的 📁 图标） |
| 一次性勾选整个空间 | 按住 `Ctrl` 再点空间名 |
| 全部选中 / 全部取消 | 点右上角「全选」「全不选」 |

**第 3 步**：点「**备份所选对话**」，等待进度条走完。

备份文件会自动存到：`D:\WorkBuddy备份\WorkBuddy备份_日期时间.zip`

> 建议先完全退出 WorkBuddy 再备份，这样文件不会被占用而漏掉。

---

## 四、恢复 / 换新电脑（4 步）

![恢复页](screenshots/02-restore.png?v=3)

**第 1 步**：新电脑装好 WorkBuddy，**登录和老电脑同一个账号**。

**第 2 步**：**彻底退出 WorkBuddy**（右下角托盘图标也要退出）。软件会强制检查这一步，没关会拦住你。

**第 3 步**：打开本软件 → 切到「恢复」页：
- 软件会**自动找出最新的备份包**并加载
- 也可以从下拉框挑其他备份包，或点「**浏览**」手动指定
- 备份包管理：点「**刷新**」重新搜索、点「**打开目录**」直达备份文件夹、点「**删除**」清理不要的备份包（先移入回收站，可在回收站还原）

**第 4 步**：勾选要恢复的对话 → 点「**恢复所选对话**」→ 完成后**重启 WorkBuddy**。

恢复时会自动做四件事：

1. **整库合并**：对话、自动化任务、空间登记、对话快照等全部数据表一次性写回（不是只写对话）；
2. **账号归属对齐**：把恢复的数据挂到当前登录账号名下（`user_id` 改写），确保 WorkBuddy 界面能显示出来 —— 这是换电脑后"看不到恢复内容"的常见原因，本工具已自动处理；
3. **路径改写**：旧用户名、旧工作区目录自动改写成新电脑路径；
4. **安全兜底**：恢复前自动把当前数据库备份为 `.bak` 文件，出错可回滚。

> 恢复前请**先启动并登录 WorkBuddy**（让本机生成账号信息），然后关闭它再恢复 —— 这样账号归属对齐最准确。

## 五、设置项说明（右上角 ⚙️）

![设置页](screenshots/03-settings.png?v=3)

| 选项 | 说明 |
|------|--------|
| 备份保存位置 | 备份包存哪儿，默认 D 盘的「WorkBuddy备份」文件夹 |
| WorkBuddy 数据目录 | 对话记录存在哪儿，**一般不用改**，软件已自动检测好 |
| 项目工作空间根目录 | 你写的代码存在哪儿，**一般不用改** |
| 内置缓存排除（4 项） | 都是 WorkBuddy 能自己重新生成的临时文件，不备份可以省空间、速度快；**不影响任何对话和代码** |
| 跳过文件夹（node_modules 等） | 这些是依赖包/编译产物，随时能重新下载或重新编译；**你亲手写的代码一个都不会少** |

点「**重新检测**」可以让软件重新扫描并自动填好路径。

## 六、常见问题

**Q：换电脑后对话能 100% 回来吗？**
A：只要**登录同一账号** + 用的是本工具做的备份，对话正文、自动化任务、代码都会回来。恢复后重启 WorkBuddy 即可看到。

**Q：会不会把我的桌面弄乱？**
A：不会。软件只在 `%LOCALAPPDATA%\WorkBuddyBackup` 里写日志和配置，桌面干干净净。

**Q：为什么要求恢复前关闭 WorkBuddy？**
A：恢复要写入它的数据库，程序正在运行时写入会导致数据损坏，所以必须退出后再恢复。

**Q：桌面图标显示的还是旧图标？**
A：Windows 图标缓存问题。桌面按 `F5` 刷新，或注销重新登录就正常了。

**Q：启动时有个"正在启动"画面？**
A：正常。单文件程序每次启动要解压自身（约几秒），显示画面是让你知道它在启动，不是卡住了。

**Q：备份包有多大？**
A：取决于你勾选的对话和代码量。排除了缓存和依赖目录后，通常远小于原始体积。

## 七、安全与隐私

- **纯本地运行**：所有备份/恢复都在你自己的电脑上完成，不联网、不上传任何数据。
- **不含账号信息**：备份包里没有密码或登录凭证，换电脑后需自行登录同一账号。
- **公开可查**：工具本体与说明全部公开，可自行审查。

## 八、技术说明

Python 3 + PyQt6 开发，PyInstaller 单文件打包（含启动画面与自定义图标）。
数据库采用 SQLite 全表合并策略，恢复时逐表 `INSERT OR REPLACE`，保证自动化任务、空间登记、对话快照一并还原；备份前执行 `wal_checkpoint` 确保包含最新数据。

## 🔨 从源码自行打包

```bash
# 1. 安装依赖（Python 3.10+）
pip install -r requirements.txt

# 2. 生成图标与启动画面（可选，仓库已带成品）
python tools/make_icon.py
python tools/make_splash.py

# 3. 打包单文件 exe
pip install pyinstaller
pyinstaller WorkBuddyBackup.spec --noconfirm
# 产物在 dist/WorkBuddyBackup.exe
```
